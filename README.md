# Device Tester

Веб-инструмент для проверки устройств. Сейчас доступен **Mouse Tester**: проверяет кнопки мыши, колёсико и двойной клик, подсвечивая нужную часть схемы мыши.


## Стек

React, TypeScript, Vite, Tailwind CSS, lucide-react

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
